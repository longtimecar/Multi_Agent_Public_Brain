# Style routing for the faceless earning plan

## Recommended first series: AI memory and independent development

| Topic beat | Motion language | Why it fits | Suggested format |
|---|---|---|---|
| “AI 为什么又忘了我？” | G2 信号故障 + A3 大字冲击 | Immediate hook and a visible failure state | 15–25s vertical |
| “没有长期记忆 / 有长期记忆” | F3 分屏对比 | Explains a difference without showing a face | 25–40s vertical or 60–90s horizontal |
| “一个偏好如何变成可迁移记忆” | B3 粒子聚形 | Turns an abstract data concept into a memorable visual | 30–60s |
| “我今天删掉了一个功能” | A2 光标打字 + B-style quiet motion | Builds a serial diary feeling | 20–35s |
| “一句话为什么能改变 AI 的回答” | A3 大字冲击 + F3 comparison | Strong hook followed by a quick example | 15–30s |

## Production checklist

- Decide: vertical 1080×1920 or horizontal 1920×1080.
- Put the hook in the first 1–2 seconds.
- Use one visual metaphor per video.
- Keep text large enough for a phone screen.
- Make all random values deterministic.
- Add music and sound effects unless the user explicitly wants silence.
- End with a question or observation that invites comments, not a forced sales pitch.
- Export a clean master and platform-specific crops.
